# 配字

默认样式是本项目最终确认版本，可被用户当次偏好覆盖：32px/720p等比、PingFangSC-Semibold、横宽90%、字距1.15px、#6C52B1到#1E8A7A渐变，0.45s淡入与0.45s淡出，smoothstep。

所有字卡固定，不横移、不缩放、不加底色矩形。正文与片尾同级。根据实际镜头寻找留白，不能裁猫或改背景来腾位置。

```json
{"text":"小猫，大有可爱。","start":4.85,"end":7,"x":0.1,"y":0.71,"align":"left"}
```

x/y归一化0–1，y从底部计。left时x为文字左缘，center时x为文字中心。字号统一由style控制。renderer检查越界并给阅读停留诊断。

首句在侧边留白，不贴顶；大脸镜头用固定侧边字卡。拥抱、玩耍避开手、羽毛和猫。造型两句“五种造型，一样可爱。　每一面，都有偏爱。”一行同进同出，通常覆盖实际正面和侧背队列约4秒；长行要避开抬起的尾巴。俯视、嗅鼻和高潮可以不加字。

片尾单猫可能很大，使用空白侧，不把名字压在耳朵上。可在队列末段提前柔和出现以增加停留；不能为了字幕静止或延长视频。

两个0.45秒渐变占0.9秒。全亮停留至少约0.75秒，长句更久；不要把整个1.1秒窗口当“停留1.1秒”。captions-template只是待检查草稿，换猫名后按真实镜头调整。

最后两行草稿的end_at_video_end为true；assemble按实际原片完整时长解析字幕终点，不裁切视频。

字幕和 [旁白稿](narration.md) 独立编辑：配音可用更短的句子，无需逐字念完所有字卡。字幕的显示时段不等同于实际讲话窗口，混音使用narration.timing.json。
